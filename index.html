# Política de Privacidade — PokéHelmet **Última atualização:** 14 de outubro de 2026 ## 1. Introdução O PokéHelmet é um bot de entretenimento para Discord que oferece funcionalidades de captura e coleção de Pokémon, Pokédex, economia virtual, trocas e outros recursos de jogo. Esta política explica quais dados são armazenados, como são utilizados e como os usuários podem solicitar sua exclusão. ## 2. Dados armazenados O PokéHelmet armazena o ID da conta do Discord dos usuários para associar e identificar seus dados de jogo. Esses dados podem incluir Pokémon capturados, moedas virtuais, inventário, progresso e outras informações necessárias às funcionalidades utilizadas. ## 3. Finalidade do uso dos dados Os dados são utilizados para manter o progresso dos jogadores, registrar capturas, administrar coleções, gerenciar a economia virtual e permitir o funcionamento dos demais recursos do bot. ## 4. Armazenamento e segurança Os dados são armazenados no Firebase. São adotadas medidas técnicas e administrativas destinadas a proteger as informações contra acessos não autorizados, alterações e exclusões indevidas. Nenhum sistema pode garantir segurança absoluta. ## 5. Compartilhamento Os dados não são vendidos. O Firebase é utilizado como serviço de infraestrutura para armazenar as informações necessárias ao funcionamento do bot. Os dados poderão ser divulgados quando houver obrigação legal aplicável. ## 6. Retenção e exclusão Os dados são mantidos enquanto forem necessários ao funcionamento do serviço, respeitadas as obrigações legais aplicáveis. Os usuários podem solicitar a exclusão dos dados associados ao seu ID do Discord por mensagem privada (DM) ao responsável pelo PokéHelmet no Discord. As solicitações serão analisadas e atendidas conforme as obrigações legais aplicáveis. ## 7. Alterações desta política Esta política poderá ser atualizada para refletir mudanças no funcionamento do PokéHelmet ou nas práticas de tratamento de dados. A versão vigente será publicada nesta página. ## 8. Contato Para dúvidas, questões relacionadas à privacidade ou solicitações de acesso e exclusão de dados, entre em contato com o responsável pelo PokéHelmet por mensagem privada no Discord.
